# MPI IPAS Kelas IV – Petualangan Mengenal Bagian Tumbuhan

## GitHub Pages
1. Buat repository baru di GitHub.
2. Upload `index.html` ke bagian paling atas (root) repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu **Save**.
6. Setelah selesai, alamat biasanya berbentuk:
   `https://USERNAME.github.io/NAMA-REPOSITORY/`

## Netlify
1. Masuk ke Netlify.
2. Pilih **Add new site / Deploy manually**.
3. Upload folder ini atau file `index.html`.
4. Netlify akan memberikan alamat publik berakhiran `.netlify.app`.

File `index.html` sudah menjadi halaman utama dan tidak memerlukan rename lagi.
